================================================================================
ISSUE #12 (GITHUB ISSUE #24): AGGREGATED MULTI-REPO IMPACT REPORT GENERATOR
================================================================================

1. OVERVIEW & MOTIVATION
--------------------------------------------------------------------------------
When an API change impacts multiple consumer repositories across a GitHub Organization
(e.g., `web-frontend`, `admin-dashboard`, `mobile-app`), Sentinel must aggregate findings
across repositories into a unified, collapsible PR comment and Check Run summary.
Engineers reviewing provider PRs can expand individual consumer repositories to view
exact code snippets and follow deep links directly to the impacted source lines on GitHub.

2. ARCHITECTURAL IMPLEMENTATION
--------------------------------------------------------------------------------
- Target Module: `src/github/reporter.ts` & `src/types.ts`
- Schema Enhancements:
  - Added `repositoryName?: string` and `commitSha?: string` to `ConsumerFinding`.
  - Added `RepoScanStatus` and `repoStatuses?: RepoScanStatus[]` to `ChangeReport`.
- Core Functions & Reporting Features:
  - `buildGitHubFileLineLink(filePath, lineNumber, repositoryName, commitSha, defaultOwner)`:
    - Constructs deep GitHub line URLs:
      `https://github.com/${fullRepo}/blob/${commitSha}/${filePath}#L${lineNumber}`
    - Formats as markdown links: `[\`${filePath}:${lineNumber}\`](url)`.
  - `formatComment(report, timestamp, options)`:
    - Groups consumer findings by `repositoryName`.
    - Computes summary badge: `Total Detected Usages: X across Y consumer repositories`.
    - Renders collapsible `<details><summary>📦 repositoryName (N usages)</summary>` blocks.
    - Within each repository block, groups usages by confidence level (CONFIRMED, HIGH, MEDIUM)
      with direct line hyperlinks and code snippets.
    - Renders organization repository permission statuses (e.g. `Unable to determine (Permission Denied)`).
  - `formatCheckRunSummary(report, schemaFilePath)`:
    - Includes `📦 Consumer Repositories` metric in Check Run summary tables.
    - Annotates consumer file findings with repository prefixes (`[repoName] file:line`).
